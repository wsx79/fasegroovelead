# Changelog

*🇮🇹 [Versione italiana](CHANGELOG.it.md)*

All notable changes to **Fase Groove Lead**.

## 0.1.2 — 2026-10-26

- Pinned shared-module SHA and complete inventory checked offline and against its canonical source in CI; Lead included in default sync/check.
- Translation catalogs checked for duplicate keys, including multiline entries; intentional common/product overrides remain supported.
- Shared panel drawing replaces identical local helpers; layout, controls and musical generation remain unchanged.

## [0.1.1] - 2026-10-25

- Global octave control for all lead lanes, saved in presets and available to host automation.
- Audition, MIDI export and guide audio use the same octave setting.

## [0.1.0] - 2026-10-25

- First release: monophonic lead melodies in the thirteen Fase Groove house genres, with repeatable motifs, harmony-aware resolutions and scale-based passing notes.
- Twelve melodic phrase lanes, shared family editor, random generation, A–D parts, humanize, sections, fills and arrangement.
- Four internal lead synth sounds, MIDI/WAV export, MIDI import, presets, LINK and KEY.
- VST3 and Standalone for Windows, macOS and Linux; AU for macOS. Windows installer and portable packages follow the family release workflow.
- English and Italian user guides, with installation, every control, routing and export instructions.
