# Privacy – Fase Groove Lead

*Ultimo aggiornamento: 19 ottobre 2026 · 🇬🇧 [English version](PRIVACY.md)*

Fase Groove Lead rispetta la tua privacy nel modo più semplice possibile: **non raccoglie nulla**.

- **Nessun dato personale** viene raccolto, salvato o inviato.
- **Nessuna statistica, telemetria, pubblicità o controllo di licenza.**
- **Controllo facoltativo degli aggiornamenti.** All’apertura, una volta per sessione, il plugin interroga GitHub e può scaricare una nuova versione. GitHub riceve l’indirizzo IP e lo user agent "FaseGrooveLead-Updater" della richiesta. Griglie, note MIDI, campioni e progetti non vengono inviati. Il controllo automatico è attivo per impostazione predefinita e si può disattivare in **OPZIONI → IMPOSTAZIONI**; il controllo manuale resta disponibile.
- **Nessun account** e nessuna registrazione.

## Cosa resta sul tuo computer

| Cosa | Dove | Perché |
|---|---|---|
| Impostazioni del plug-in, la tua griglia e i percorsi dei tuoi campioni | Nel progetto della DAW | Per ritrovarle quando riapri il progetto (le salva la DAW). |
| Clip MIDI trascinate | `Documenti/Fase Groove Lead/MIDI clips/` | Il trascinamento nella DAW richiede un file reale. Puoi cancellarle quando vuoi. |
| File `.mid` salvati con *SAVE .MID* | Dove scegli tu | Su tua richiesta. |
| Lingua dell'interfaccia | `Fase Groove Lead.settings` nella cartella delle impostazioni utente del sistema | Per mantenere la tua lingua in ogni progetto. |
| Impostazioni audio/MIDI dell'app Standalone | La cartella delle impostazioni utente del sistema | Gestite dal framework JUCE per ricordare la tua scheda audio. |
